# ADR-0004: PostgreSQL with Drizzle ORM (not Prisma)

- Status: accepted · Date: 2026-10-29 · Decider: Chief Architect, with Senior Developer

## Context
The brief allows Prisma or Drizzle. We deploy to Cloudflare Workers (ADR-0003).

## Decision
Drizzle ORM + `postgres.js` driver; migrations generated by `drizzle-kit` and committed as SQL.

## Consequences
- No query-engine binary, small bundle, runs on Workers and Node unchanged.
- Schema is TypeScript (`src/server/db/schema.ts`) and migrations are plain, reviewable SQL.

## Alternatives considered
Prisma (heavier on Workers, needs driver adapters); raw SQL (loses type safety).
